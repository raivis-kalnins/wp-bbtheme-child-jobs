# Jobs Theme 3.8.10.87 upgrade notes

## What changed

- Homepage 1 has a new final design layer based on the supplied Jobs reference.
- Homepage 2 / **High-volume Hiring Demo** is now visible under **For Employers** in the public submenu and employer mega menu.
- Homepage 1 keeps **One marketplace, two clear journeys** but removes the extra employer showcase and generic bottom CTA to stay closer to the reference layout.
- Light mode uses the green/teal + navy palette consistently; dark mode now uses deep teal surfaces and mint accents instead of royal blue.
- The Homepage 1 demo hero image is `assets/img/demo/jobs-hero-reference.jpg`, cropped from the supplied design reference.

## After installing

1. Replace the existing child theme with 3.8.10.87.
2. On the first wp-admin request after upgrade, 3.8.10.87 automatically refreshes the Jobs-managed portal pages once, including `/home-2/`. **HR Jobs → Setup & Demo → Create / refresh Jobs pages** remains available as a manual repair action.
3. If the site's managed navigation was generated by Starter Setup, run the parent theme's menu/navigation refresh once so the **For Employers → High-volume Hiring Demo** submenu is persisted into existing WordPress menus. The dynamic mega-menu link is available immediately from the theme filter.
4. Clear page/cache/CDN caches and hard-refresh the browser so `jobs-v87.css` is loaded.
5. Check both light and dark modes on Homepage 1, `/home-2/`, salary guide, employer dashboard and candidate forms.
